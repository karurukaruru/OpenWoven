# OpenWoven

[English](README.en.md)

一个带长期记忆、能主动发消息的 Android 聊天 App，用你自己配置的模型聊天。

## 怎么来的

最开始只是想试一下，能不能做个会慢慢熟悉你的聊天对象。

我之前做过一个 ASM（Agent Software Map），让 Agent 把软件怎么操作记下来，下次再拿出来用。后来做棉花娃娃互动的时候，把这个想法改了一下：既然能学软件，那能不能学人？

我把这部分叫 AUL，AI User Learning。名字是随便取的，做的事情也没那么玄学：记住用户喜欢怎么聊天，再根据后面的交流慢慢调整。

## 现在做了什么

先问十个问题，了解一点用户，也了解用户想和什么样的角色聊天。愿意多填的话可以回答五十题，不确定的可以先空着。

这些问题只是起点。比如一开始说喜欢详细回复，聊着聊着又觉得太长了，那就应该能改，而不是填完问卷就把人定义死。聊天里的明确表达和“太长了”“追问太多”这类反馈，会用来调整后面的回复。角色的设定和已经说过的经历也会记下来，尽量保持前后一致。

消息尽量按日常聊天的习惯发。几句话拆成几条，中间稍微隔一下；你还在输入的时候先等等，不是一发消息就立刻回来一大段。

它也能主动找你。可以自己设定发送时间和内容，也可以让模型到时候找个话题。主动消息有次数和免打扰设置，安卓这边会发通知，不过后台能不能按时跑还得看手机的限制。

聊天记录按日、周、月整理，原话也留着。以后提起以前聊过的事，可以按日期和关键词找回相关内容，不用每次都把全部聊天记录塞进上下文。

另外也有模型切换、图片发送和聊天反馈。图片需要你配置的模型支持看图。

## 怎么用

Android 8.0 及以上。

打开 App，先填初始问题，然后到设置里配置接口地址、模型和自己的 API Key。角色和昵称可以让当前模型生成，确认后再开始聊；想收到主动消息的话，记得允许通知。

模型调用可能产生费用，相关对话也会发给你配置的服务商。目前仓库还没有提供正式 APK 下载，可以按 [源码构建说明](CONTRIBUTING.md#android) 自己构建。

想先不接 API 看看它怎么学习偏好，可以运行 Python 演示（Python 3.11+）：

```sh
python -m pip install -e .
python -m openwoven --db ":memory:" demo
```

这个演示用的是示例回复，不是真实模型。

## 现在怎么样

安卓端大体能跑了，但还比较糙。我自己也没认真用多久，所以 AUL 到底有没有用、长期记忆整理几次以后还记不记得清楚，这些现在都不好说。

先把它开源出来，后面再慢慢用、慢慢修。有问题可以提 Issue，别把自己的 API Key 或私人聊天记录贴上来。
